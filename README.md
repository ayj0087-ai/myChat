# myChat — 규정 기반 RAG 챗봇

Claude를 사용해 등록된 규정의 관련 구간을 검색하고 근거 번호와 함께 답변하는 한국어 웹앱입니다.

## 사용법
1. 앱의 규정 자료실에서 **폴더 선택** 또는 **파일 추가**를 누릅니다.
2. PDF(텍스트 포함), DOCX, UTF-8 TXT/MD를 등록합니다. 파일당 20MB, PDF당 300쪽, 전체 15,000개 검색 구간까지입니다.
3. 모델 및 API 설정에 Anthropic API 키를 입력합니다. 기본 모델은 `claude-sonnet-4-5`이며 사용 가능한 모델 ID로 변경할 수 있습니다.
4. 질문을 보내고 [1] 등의 근거 버튼으로 발췌문을 확인합니다.

## 데이터와 보안
- 문서 텍스트와 색인은 브라우저 IndexedDB에 보관됩니다. 서버·GitHub에 규정 파일을 저장하지 않습니다.
- API 키는 React 메모리에만 보관하며 새로고침 시 삭제됩니다. 서버는 요청 중에만 사용합니다.
- 질문과 검색된 상위 6개 구간이 사이트 서버를 거쳐 Anthropic API로 전송됩니다. API 사용료가 발생합니다.
- Vercel에서 실행되는 무상태 API이며 사용자가 입력한 본인 키로만 호출합니다. 서버 공용 키나 공유 문서 저장소는 없습니다.
- 폴더는 가져오기 방식이며 자동 감시하지 않습니다. 수정한 폴더를 다시 선택하면 같은 경로의 문서를 교체합니다. 폴더에서 삭제한 파일은 자료실에서 별도로 삭제하세요.
- 다른 기기/브라우저에는 자동 동기화되지 않습니다. 브라우저 데이터 삭제 시 자료도 삭제됩니다.

## 검색 구조
파일 파싱 → 1,100자 구간(250자 중복) → 한국어 단어 및 2글자 n-gram BM25 검색 → 상위 6개 근거 → Claude Messages API → 인용 및 발췌문 표시.
이 버전은 **어휘 기반 RAG**입니다. 임베딩 벡터 검색이나 동의어 의미 검색은 구현하지 않았습니다. 근거가 없을 때 모델을 호출하지 않습니다. 인용의 정확성은 원문과 대조해야 합니다.

스캔 PDF의 OCR, HWP/HWPX 직접 파싱은 지원하지 않습니다. HWP는 PDF로 변환하고 스캔본은 OCR 후 등록하세요. DOCX는 원본 페이지 번호를 복원하지 않습니다. 각 질문은 독립적으로 검색하므로 규정명·핵심 용어를 포함하세요.

## 개발 및 검증
- `pnpm install`
- `pnpm dev` / `pnpm build`
- `node --experimental-strip-types tests/retrieval.test.ts`
- 실제 Claude 응답 검증에는 유효한 본인 API 키가 필요합니다.

규정 원본과 키는 절대 이 공개 저장소에 커밋하지 마세요.
